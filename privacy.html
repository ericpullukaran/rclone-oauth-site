Privacy policy

Eric's personal Drive sync · Last updated 11 October 2026

Purpose and operator

Eric Pullukaran operates this personal rclone installation to synchronize files between his own Google Drive account and his own computer. The installation is not offered to other users.

Information accessed and use

The OAuth client requests the Google Drive scope https://www.googleapis.com/auth/drive. This allows reading file contents and metadata and creating, modifying, or deleting Drive files. The configured sync task uses that access to synchronize a selected folder, including updates and deletions. Folder selection is a local configuration, not a restriction on the OAuth permission itself.

Storage and retention

Synchronized files are stored in Google Drive and on the operator's computer. OAuth credentials and authorization tokens are stored locally in the rclone configuration. Local sync logs, state, and backups may contain filenames, metadata, and previous file versions. Files and backups remain until the operator removes them; Google Drive may retain revisions and deleted items according to its own settings and policies.

Sharing

This installation does not sell file data, use it for advertising, or intentionally disclose it to additional third parties. Synchronization transfers data between the operator's computer and Google Drive. This public information website does not receive or host synchronized files, OAuth credentials, or authorization tokens.

Website hosting

This website uses GitHub Pages. It contains no application analytics, advertising, or sign-in form. GitHub may process technical information such as visitors' IP addresses to provide and secure its hosting service, under GitHub's privacy statement.

Control and revocation

The operator can stop synchronization at any time and revoke the app's authorization through Google Account connections. Revoking authorization stops future authorized access; it does not automatically delete existing local copies, backups, or files in Drive.

Contact and changes

For questions, use the contact options on Eric Pullukaran's GitHub profile. This policy will be updated if the installation's data handling changes.
